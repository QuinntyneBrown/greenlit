## Roadmap

1. sheet: the last gaps of view-month and mark-days (select days and the keyboard are built)
2. identity-and-access and teams: built (a manager running several teams with a default team and the header switcher, manage account, notification settings, invite, accept, Google sign-in, reset password, sign out, holidays, working days, the coverage minimum, team settings and remove member are built)
3. requests: the member's request detail (send, approve, review, decline, my requests and cancel are built; days left is built with allowances; the Decisions switch is built with notification settings)
4. web-experience: built (the app shell, toasts, connectivity, the error pages and the marketing page)
5. allowances: built (figures, the year page, the Settings Allowances section, the person page and adjustments under ADR-007; the person page's Remove section is built with remove-member)
