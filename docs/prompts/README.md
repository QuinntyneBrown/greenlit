# Implementation prompts

One ready-to-run prompt per journey in [`docs/journeys.md`](../journeys.md), written with the
`writing-feature-prompts` skill. Give a prompt to an agent as its whole task; it runs the journey from
aligning the requirement, design and mock through ATDD implementation to a PR. Run them in order: each
prompt names the journeys it builds on.
