Pagination

Pagination moves through a list that is too long for one screen, such as a long request history.

WCAG 2.2 AAStatus: provisionalSince v1.0

Overview

.pagination is a list of numbered links with previous and next arrows. Greenlit lists are short (a team under ten people, a handful of requests per status), so no shipped screen paginates yet; the component exists so a long history never becomes an unbroken scroll.

Prefer filtering with tabs or the year view over paging. Never paginate the sheet: its month is one page by design and the period navigation moves between months.

Anatomy

  1. Previous / nextIcon links with aria-label "Previous page" and "Next page"; aria-disabled="true" at the ends.
  2. Page linkNumbered 32px link; the label says "Page 3" to assistive technology.
  3. Current pagearia-current="page": accent-tinted fill, accent border and accent text.

Variants

One construction; the window of pages changes with the list length.

Sizes

Not applicable: links are always 32px (<code>--control-height-sm</code>) wide at minimum; in a dense list it sits inside a larger row.

Responsive behaviour

  • Below 640px show previous, current page and next only, plus "Page 2 of 5" as text; hide the numbered links you cannot fit, rather than scrolling.
  • From 640px show up to seven page links with a gap marker for the omitted range.
  • The list is a single row (display: flex) with 4px gaps; at 360px five items fit.
  • Keep pagination outside any horizontally scrolling table wrapper so it stays visible.

Theming

The current link is the one accent-tinted element: --color-accent-subtle fill, --color-accent border, --color-fg-accent text. Others are --color-fg-muted with a subtle hover fill. No theme-specific rules.

.pagination [aria-current="page"] { border-color: var(--color-brand); }

Accessibility

Role and pattern

A <nav aria-label="Pagination"> containing a list of links, the current one marked aria-current="page". This is the common pagination pattern in the W3C ARIA Authoring Practices guidance for navigation landmarks: no tabs or menu roles.

Keyboard

KeyAction
TabMoves through previous, each page link and next; a disabled link is still reachable and announced as dimmed.
EnterFollows the link and moves focus to the new list's heading or the first row.

Focus

Shared ring on :focus-visible. After a page change move focus to the list heading so keyboard users do not restart from the top of the page.

Labelling

Every icon-only link has an aria-label; numbered links read "Page 3" and the current one also exposes aria-current. Add a visible "Showing 11–20 of 34" line so the position is not carried by styling alone.

Contrast

Link on canvas
Current page text
Current page border
Focus ring on canvas

Motion

No motion.

Touch

Links are 32px wide and tall; on coarse pointers use the previous / current / next form so each target can be padded to 44px, and keep 4px or more between neighbours.

Content

  • Use numerals for pages, and "Previous" / "Next" as accessible names, not as visible words.
  • Show where the person is as text: "Page 2 of 5" or "Showing 11–20 of 34 requests".
  • Do not paginate fewer than 25 items.
