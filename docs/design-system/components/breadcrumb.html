Breadcrumb and back link

Back link and breadcrumb: how a person climbs one level (or several) from a detail screen.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Greenlit is shallow, so its primary pattern is the back link (.back-link): an arrow and the name of the parent screen, shown above the title of a detail page such as a person's page. One tap returns to where the person came from.

The breadcrumb (ol.breadcrumb inside nav aria-label="Breadcrumb") is defined for the rare screen that is three or more levels deep, which the product does not have today. Use a back link for one level. Use a breadcrumb only when the reader needs to jump over intermediate levels. Neither replaces the app navigation.

Anatomy

  1. Arrow iconarrow-left from the icon set, 16px, aria-hidden.
  2. LabelThe parent screen's name. It is the link's accessible name; 14px muted text, darkens on hover.

Responsive behaviour

  • The back link is one line at every width and sits above the page title with the page's own top margin; it needs no collapsing.
  • The breadcrumb wraps (flex-wrap: wrap) with 8px gaps; at 360px a three-level trail takes two lines rather than truncating.
  • Long labels (a member's full name) may use .truncate on the last item, with the full name in the title attribute only as a convenience, never as the sole carrier.
  • On phones, prefer the back link even for deeper screens: it is a single, large target.

Theming

Muted text --color-fg-muted, hover/current --color-fg-default, separators --color-fg-subtle. No theme-specific rules.

.breadcrumb li + li::before { content: "›"; }  /* chevron separator in a re-skin */

Accessibility

Role and pattern

WAI-ARIA APG Breadcrumb pattern: a <nav aria-label="Breadcrumb"> around an ordered list, the last item marked aria-current="page". The back link is a plain <a>, no landmark needed.

Keyboard

KeyAction
Tab / Shift+TabMoves between links in reading order.
EnterFollows the link.

Focus

Shared ring on :focus-visible. The back link's box includes the arrow so the ring wraps both.

Labelling

The back link's name is its visible label ("Calendar"), which is the destination. A bare "Back" is ambiguous when arriving from a bookmark. The breadcrumb landmark is labelled "Breadcrumb" so it is distinct from the main navigation.

Contrast

Back link on canvas
Hover on canvas
Separator on canvas

Motion

No animation; only an instant colour change on hover.

Touch

The back link has a minimum 24px height (--target-min); add the page's top margin so it has at least 8px clear space from the title. Breadcrumb items are 14px text with 8px gaps and are used on desktop widths.

Content

  • Back link: the parent's name ("Calendar", "Requests"), never "Back" or "Go back".
  • Breadcrumb labels are the same as the page titles they point to.
  • The current page is last and is not a destination to link to elsewhere.
  • Do not put a breadcrumb on a page that is one level below the app navigation: use the back link.
