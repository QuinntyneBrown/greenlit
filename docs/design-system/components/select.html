Component · Inputs

Select

A select chooses one value from a closed list of known options. It is the native browser control with Greenlit styling.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Use a select for choosing one value from a closed list that is too long to show at once: a time zone, a member's role. Native selects are used on purpose; they bring the platform's keyboard handling, search-by-typing and the large touch picker on phones.

For two to five options that should stay visible, use a segmented control (immediate) or a radio group (submitted with a form). For open text use a text field. For commands use a menu: a menu runs actions, a select stores a value.

Anatomy

  1. Label.field__label bound to the select with for.
  2. ChevronDrawn with two CSS gradients (appearance: none hides the native arrow); inherits currentColor.
  3. ValueThe selected option's text, in --text-body. Right padding keeps long values clear of the chevron.
  4. Help textExplains the consequence of the choice.

Variants

One style, native options.

Managers can approve requests and edit any row.
A role select in the Invite member dialog.
HTML
<div style="width: 100%; max-width: 22rem;"><div class="field"><label class="field__label" for="sel-v1">Role</label><select class="select" id="sel-v1" name="sel-v1" aria-describedby="sel-v1-help"><option value="member" selected>Member</option><option value="manager">Manager</option></select><span class="field__help" id="sel-v1-help">Managers can approve requests and edit any row.</span></div></div>

Inline in a list row

In a member row the visible label is the person's name beside it, so the select carries a visually hidden label that names the row ("Role for Ana Ruiz").
HTML
<div class="cluster"><label class="visually-hidden" for="sel-v2">Role for Ana Ruiz</label><select class="select input--sm" id="sel-v2" name="sel-v2" style="width: 100%; max-width: 8.5rem;"><option selected>Member</option><option>Manager</option></select></div>

Sizes

Same heights as the text field: medium (40px) by default, small (.input--sm, 32px) in rows.

.select alone is medium; add .input--sm for small.
HTML
<div class="stack" style="width: 100%; max-width: 20rem;"><select class="select input--sm" aria-label="Small, 32px"><option>Small · 32px</option></select><select class="select" aria-label="Medium, 40px"><option>Medium · 40px</option></select></div>

States

Hover and focus are forced for review. Invalid uses aria-invalid="true"; disabled uses the native attribute. The open option list is drawn by the browser or operating system and is not styled by the kit.

Both themes

  • Give a select a sensible default; avoid an empty "Select…" first option on short lists.
  • Selects have no loading state. If the options load asynchronously, disable the select and say so in help text.

Responsive behaviour

  • Full width of its field. In the member list a select is a fixed 8.5rem (.member-list .select); the row wraps so the select keeps this width on a phone.
  • On phones the native picker opens as a wheel or sheet; do not replace it with a custom list.
  • Long option text is truncated by the browser inside the box; keep labels under about 30 characters or widen the field.

Theming

Colours are shared with the text field. The chevron is two linear-gradients in currentColor, so it follows the text colour in both themes and in the disabled state. Option lists follow the user agent's color-scheme, declared on the document.

/* Larger chevron inset for a settings screen */
.settings .select { padding-right: var(--space-12); background-position: calc(100% - 22px) 50%, calc(100% - 17px) 50%; }

Accessibility

Role and pattern

Native <select>, which the APG recommends over a custom Combobox or listbox whenever it fits. No ARIA is added. A select with typeahead search or multi-select is a different component and does not exist in the kit.

Keyboard

KeyAction
TabMoves focus to and from the select.
Space, Enter, Alt+↓Opens the option list (browser-dependent).
↑ / ↓Changes the value (closed) or moves through options (open).
Type a characterJumps to the next option starting with it.
EscCloses the option list without changing the value.

Focus

Fields draw the same ring as every control, but inside the border: --focus-ring-width solid --color-focus-ring with zero offset, plus a border in the ring colour, so the focused edge is at least 3:1 against both the field and the page. The ring is shown for :focus-visible, which for text fields is every focus, pointer included.

Labelling

Visible <label for> and aria-describedby for help and errors. When a select sits inside a row, a visually hidden label names it with the row's subject ("Role for Ana Ruiz"). The selected option's text must make sense alone.

Contrast

Value on field
Border on page
Invalid border on field

Motion

Border colour transitions over --duration-fast. The native list's animation belongs to the platform.

Touch

40px high and full width by default; the small variant (32px) is used only in rows with at least 8px between controls. The native mobile picker is the large target.

Content

  • Label the field with the thing being chosen: "Time zone", "Role". Option text is a short noun or place: "Member", "London (GMT+0 / BST)".
  • Order options meaningfully (most common first, or geographic) rather than alphabetically by accident.
  • Do not put actions or instructions in the option list ("Add new…"); use a button.
  • Help text says what the choice changes.
