Component · Sheet and brand

Team grid

The sheet: members down the left, weekdays and dates across the top, one coloured cell per member per day, and a coverage row under the last member.

Overview

The team grid is the page's main region and the reason Greenlit exists. It is the Google Sheet's table for one month: a sticky name column, one column per day, a Left column showing remaining allowance and an Out row counting how many people are away each day. Every sheet cell inside it is a button the caller may paint, or a read-only square.

Use it for one team and one month. For a whole year at a glance use the year grid; for one person's year use the month mini; for a list of what needs approving use the request row. Do not use a grid to lay out forms or generic data tables: use table.

Anatomy

  1. Corner.grid-corner: sticky, empty, with a visually hidden "Team member" so the column has a header.
  2. Column header.grid-colhead per day: weekday initial over .date-chip; today has aria-current="date".
  3. Name cell (row header).grid-name, role="rowheader": avatar, name, optional .grid-name__you. Sticky to the left edge.
  4. Allowance column.grid-left, only with .team-grid--left. data-over turns it danger-coloured.
  5. Coverage row.cover in a row whose header is .grid-name--cover ("Out"): the count of people away; data-level none, some (default) or short.
  6. CellsOne sheet cell per day, role="gridcell". Weekends and holidays are read-only red.

Responsive behaviour

  • The grid is always wrapped in .grid-card (overflow-x: auto, surface background, --radius-lg corners). A 30-day month needs about 51rem; below that the card scrolls sideways, never the page.
  • Sticky first column: .grid-corner and .grid-name are position: sticky; left: 0 on --color-bg-surface so names stay visible while days scroll beneath them. The name column is minmax(8.25rem, 11rem); long names ellipsise with the full name in a link or title.
  • Padding steps from --space-3 to --space-4 at --layout-breakpoint-md (48rem). Column gaps stay --space-0-5.
  • At 360px roughly six day columns are visible beside the name column. Scroll position is not reset when the month changes; the page title and legend stay above the card.
  • Touch: press and drag across cells paints a range; a tap selects a cell and opens the selection bar, which holds the actions at 32px+ targets. Horizontal scrolling uses the card, so start a drag on a cell, not the header, to paint.
  • Wide screens do not add columns: the grid fills --layout-container-max and cells widen with 1fr.

Theming

The grid contains no colours of its own. It reads --color-bg-surface (sticky cells and card), --color-border-default (card edge), the status tokens through the cells, --color-danger-fg for weekend headers and over allowance, --color-bg-subtle for the coverage fill and --cell-height and --space-0-5 for density.

/* Denser sheet for a large TV display: only the tokens change */
.tv-sheet { --cell-height: 3.25rem; }
.tv-sheet .team-grid { gap: var(--space-1); }

Dark theme swaps the status tokens (green-400, blue-400, coral-400) and the surface; ink glyphs remain legible on all of them.

Accessibility

Role and pattern

An ARIA grid (APG grid pattern): role="grid" with an aria-label ("Time off, July 2026"), role="row" children (display: contents keeps the CSS grid flat), columnheader for each day, rowheader for each member and gridcell for each cell. Interactive cells hold a <button> with aria-pressed. The grid is aria-busy="true" while loading. A roving tabindex keeps one tab stop: the active cell has tabindex="0", all others -1.

Keyboard

KeyAction
TabMoves focus into the grid at the active cell, and out to the next control. The grid is one tab stop.
← →Moves the active cell one day; at the edge of a row it stops.
↑ ↓Moves to the same day in the previous or next member row (manager) or stays on your row (member).
Home / EndFirst or last day of the month in the row.
Ctrl+Home / EndFirst cell of the grid / last cell.
Space / EnterPaints the active cell with the chosen paint status, or toggles it into the selection in Select mode.
Shift+← →Extends the selection by a day in that direction (range select) and opens the selection bar.
EscClears the selection and closes the selection bar.

Focus

Focus is a ring drawn inside the cell (see sheet cell) and is always visible; it moves with the arrow keys. The sticky name column never covers the focused cell: scroll the card so the cell is clear of the 11rem name column (use scroll-margin-left equal to the column width on cells).

Labelling

The grid is named "Time off, July 2026". Each member row is announced by its row header ("Ana Ruiz, You"). Each cell reads "Ana Ruiz, Tue 14 Jul: Confirmed" so state is in the accessible name, not in a colour. Weekday initials are aria-hidden; the column header's aria-label ("Tue 14 Jul") is announced instead. Coverage cells are role="img" with a name ("3 out, 3 in. Below the minimum of 4"). Selection changes are announced in a polite live region ("3 days selected, 2 over allowance").

Motion

The grid animates nothing except the skeleton shimmer, which stops under prefers-reduced-motion. Selection and painting apply instantly.

Touch

Drag-to-paint uses pointer events; the grid sets user-select: none so dragging does not select text. A tap selects, and the selection bar offers 32px actions. Provide the keyboard path above as the equivalent of dragging (WCAG 2.5.1 and 2.1.1). Cells are 24px wide at minimum; do not shrink the column track below 1.5rem.

Content

  • Grid name: "Time off, ". Row header: the member's name; "You" follows your own name.
  • Column header names: three-letter weekday, day number and month ("Fri 10 Jul"). Holiday names go in the date chip's title and the cell name.
  • The allowance column is headed "Left" and shows a whole number of days; negative numbers use a hyphen-minus ("-2").
  • The coverage row is headed "Out" and counts people away (confirmed and requested). Say "3 out, 3 in" in names, not "50% coverage".
  • Hint text under the sheet is imperative and short: "Click or drag across your own row to request time off."

Drift fixed during extraction:

  • .cover[data-level="ok"] is not in components.css; the mocks use data-level="some", which has no rule either and falls back to the base .cover style. Only none and short are styled. Document and use some.
  • The mocks do not implement the roving tabindex, arrow-key, Home/End or Shift+arrow behaviour; only "Click or drag, or press Enter then arrow keys, Escape clears" is stated. The keyboard table here is the contract the Angular grid must meet (APG grid).
  • There is no scroll-margin on cells, so a focused cell can sit under the sticky name column. Suggested: .cell { scroll-margin-left: 11rem; }.
  • Left-column overage is red text plus a negative sign; the title carries the detail.
