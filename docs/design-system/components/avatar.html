Avatar

A round badge with a member's initials (or photo) that makes rows and menus recognisable at a glance. Four sizes, a stacked group, and the compact version in the team grid.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

An avatar identifies a member next to their name: in the team grid's name column, a request row, the member list, the top bar's account button. It is a recognition aid, never the only identifier: the name is always in text beside it, so the avatar is decorative and hidden from assistive technology.

Avatars show the member's initials by default (two letters, first and last name). A photo is allowed where one exists. Do not use an avatar to show status, and do not use colour to tell members apart; the sheet uses colour only for day status. A count of people is a badge or a number, not an avatar.

Anatomy

  1. InitialsOne or two capital letters in label type; scale with the size modifier.
  2. Disc--radius-full, subtle fill with muted text, clips the optional <img> with overflow: hidden.

Variants

The same disc in four contexts.

ARMC
Initials, and a photo. The photo fills the disc with object-fit: cover and carries a real alt only when the avatar stands alone; beside a name use alt="".

Grid name

ARAna Ruiz (you)
In the team grid, .grid-name .avatar shrinks to 1.5rem so a row stays one cell tall. The name is the link; .grid-name__you marks the signed-in member.

Account button

.avatar-btn wraps a small avatar and a chevron into the top bar's menu trigger. The button takes the name; the avatar is decorative.
HTML

Sizes

Pick the size from the row it sits in, not from the importance of the member.

ARMCDPFM
Small 32px (tables, lists, menus), medium 40px (default), large 56px, extra large 64px (person page header). The team grid uses a 24px variant through .grid-name .avatar.
HTML
<span class="avatar avatar--sm" aria-hidden="true">AR</span><span class="avatar" aria-hidden="true">MC</span><span class="avatar avatar--lg" aria-hidden="true">DP</span><span class="avatar avatar--xl" aria-hidden="true">FM</span>
  • Sizes: .avatar--sm 2rem / --font-size-xs; default 2.5rem; .avatar--lg 3.5rem / --font-size-lg; .avatar--xl 4rem / --font-size-xl.
  • Initials are two letters at every size; only the person header may show a first name beside it.

Responsive behaviour

  • Avatars never resize with the viewport: they are fixed rem sizes, flex: none, so a long name wraps or truncates while the disc keeps its shape.
  • In the team grid the name column is sticky and the avatar stays 24px at every width; below 48rem the grid scrolls sideways, not the avatar.
  • The person header places the extra-large avatar beside the name at all widths; the big number moves below it under 48rem.
  • A group wider than its container is truncated to the first three discs plus a count in text, never wrapped.

Theming

The disc uses --color-bg-subtle with --color-fg-muted text. (The earlier --color-accent-subtle tint is overridden further down the stylesheet; see drift.) The group's ring reads --color-bg-surface, so it follows whatever the avatar sits on in either theme.

/* Tint avatars with the brand for the person header only */
.person-head .avatar { background: var(--color-accent-subtle); color: var(--color-fg-accent); }

Accessibility

Role and pattern

A decorative image: initials are aria-hidden="true" beside the visible name. A photo beside a name uses alt="". If an avatar ever stands alone it is role="img" with an aria-label of the person's name. A clickable avatar is a <button> (menu trigger pattern); there is no ARIA avatar role.

Keyboard

KeyAction
TabReaches only the wrapper (account button or name link); the avatar is not a tab stop.
Enter, Space on the account buttonOpens the account menu; Esc closes it and returns focus.

Focus

The account button shows the shared focus ring around the whole avatar-and-chevron. The ring is drawn outside the disc, so the group's overlap never hides it.

Labelling

Beside a name: hidden from assistive technology, because the name already says it. In a group, one aria-label on the group lists the members ("Out this week: Ana Ruiz, Maya Chen, Dev Patel"). The account button's label names the person and the action: "Account menu for Maya Chen".

Contrast

Initials on avatar disc
Initials on brand tint (person header)
Group ring on surface

Motion

No motion. A photo that loads late swaps in without a fade.

Touch

The avatar is not a target. The account button including its padding is 40px tall; the top bar keeps it 8px from neighbours.

Content

  • Initials: first letter of the first name and of the last name, capitals: "Ana Ruiz" is "AR". One word gives one letter.
  • Always show the full name beside the avatar. Never rely on the disc alone.
  • Use "(you)" after the signed-in member's name in the grid, not a different avatar.
  • Photo alt text is the person's name only when the photo stands alone.
