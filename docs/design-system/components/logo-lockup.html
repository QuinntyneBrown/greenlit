Component · Sheet and brand

Logo lockup

The Greenlit mark and wordmark: a month in miniature, with four cells tracing a check, and the lowercase name with a green dot on the i.

Overview

The logo lockup is the one place the brand appears: the top bar of the app, the card above every auth form, and the brand guide. The mark is a 4 by 3 grid of rounded cells, the same shape as one week-row of the sheet repeated; four cells are filled with the brand green and trace a check. The wordmark is set in Plus Jakarta Sans 800, lowercase, with a dotless i whose dot is drawn in green.

Use the lockup wherever the product identifies itself. Use the mark alone (.mark) only where a square space leaves no room for the word, such as an app icon or a favicon. Do not use the lockup as navigation chrome decoration: inside the app it is the link home (see top bar); on an auth card it is a plain image (see card).

Anatomy

  1. MarkTwelve 8-unit cells on an 11-unit pitch, viewBox 0 0 41 30. Eight cells are .mark__n (ink at 12%), four are .mark__c (brand green). Height is 0.72em, so the mark scales with the lockup's font-size.
  2. Wordmark.logo-lockup__word: display family, weight 800, tracking -0.045em, lowercase. It is aria-hidden; the lockup itself carries the name.
  3. Green dot.logo-lockup__i::after draws a square dot over a dotless i (ı) in --color-brand. It is decorative.

Clear space and minimum size

greenlıt
Clear space is 0.5em on every side, measured in the lockup's own font-size (about the height of the lowercase letters). Nothing else, including other logos, text and edges, enters the dashed area.
  • Minimum size: the lockup is never smaller than --font-size-md (16px), where the mark is about 11px tall. The mark alone is never smaller than 1rem.
  • Do not recolour the cells, change the check, outline or add shadow to the wordmark, stretch it, or set it in another family.
  • Do not put the lockup on a photograph or a status colour. Use paper, canvas or ink.

States

The lockup is static artwork; the only interactive case is the home link in the top bar.

  • Focus shows the shared focus ring around the whole lockup.
  • Disabled, loading, selected do not exist: the lockup is never a control that changes state.

The wordmark and the neutral cells follow --color-fg-default; the green dot and the four filled cells stay --color-brand in both themes (green-500 reads on paper and on ink).

Responsive behaviour

  • The lockup never wraps and never truncates; the mark and word are one inline-flex row with a 0.28em gap.
  • In the top bar the lockup keeps its 24px size at every width and the bar hides secondary items first. Below 360px the wordmark stays; the nav collapses.
  • On auth screens the large lockup (48px) sits centred above the card; on a phone it is the only thing above the form, with --space-6 beneath it.
  • The link target is the full lockup: about 131 by 29px at 24px, which meets the 24px minimum target (WCAG 2.5.8); the top bar adds min-height: var(--layout-topbar-height) so the tappable area is the full bar height.

Theming

The lockup reads three semantic tokens: --color-fg-default for the wordmark and (at 12%) the neutral cells, --color-brand for the filled cells and the dot, and --font-family-display for the word. A theme change recolours it automatically.

/* A partner skin changes the brand colour; the artwork is untouched */
[data-theme="partner"] { --color-brand: var(--palette-blue-500); }

The artwork files assets/greenlit-mark.svg, greenlit-icon-green.svg and logo.svg are for places that cannot load CSS (favicons, app stores, email). In the app always use the inline SVG so the colours follow the theme.

Accessibility

Role and pattern

A static lockup is role="img" with aria-label="Greenlit"; the inner SVG and wordmark are aria-hidden so the name is read once. A linked lockup is an <a href> whose aria-label names the destination.

Keyboard

KeyAction
TabLinked lockup only: focuses the home link.
EnterLinked lockup only: follows the link.
SpaceNo effect on a link (use Enter).

Focus

The linked lockup draws the shared focus ring (--focus-ring-width solid --color-focus-ring) around the whole mark and word. A static lockup is not focusable.

Labelling

Accessible name is "Greenlit" (static) or "Greenlit, team calendar" (home link). Do not repeat the name in adjacent text. The stylised dotless i is hidden from assistive technology, so screen readers never read "greenlıt".

Motion

No motion. The lockup does not animate on load or hover.

Touch

The linked lockup is wider than 44px and as tall as the top bar (56px), so it is an easy target. It sits at least 8px from neighbouring controls.

Content

  • The name is always Greenlit, one word, capital G in running text; the wordmark itself is lowercase artwork ("greenlit") and is never typed.
  • Never abbreviate the name in UI copy ("GL"). The two-letter initials on an avatar are a person's, not the brand's.
  • Alt and aria text is "Greenlit", or "Greenlit, team calendar" when it links home. Do not add "logo" ("Greenlit logo") because the role already says image.
