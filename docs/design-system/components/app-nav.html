Component · Navigation

App navigation

The app navigation is the four-link row in the top bar: Calendar, Year, Requests and Settings.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

.app-nav is a <nav aria-label="Main"> of .app-nav__link anchors. The current page carries aria-current="page", which both announces it and draws a 2px brand underline. Requests may show a .count-pill with the number of pending requests; the manager sees it, and it disappears at zero.

Use it for the product's top-level destinations only. Switching between views of the same data (Pending, Approved, Declined) is tabs; sections of one long page are settings navigation; moving back up is a back link.

Anatomy

  1. Link.app-nav__link, label font, muted text; 44px tall on phones, full bar height from 768px.
  2. Count pill.count-pill on the yellow Requested status colour with a spoken suffix ("4 pending").
  3. Current-page indicator2px brand underline drawn by ::after when aria-current="page" is set; the text also darkens.

  • Current is carried by aria-current="page", darker text and the underline: three signals, so it is not colour-only.
  • Pressed and disabled do not exist: a destination the person may not open is not shown.

Responsive behaviour

  • Below 768px the nav leaves the top row and becomes a full-width second row (order: 3) with horizontal scrolling and hidden scrollbar; -12px side margins let it touch the screen edge while links keep 12px padding.
  • From 768px (--layout-breakpoint-md) it sits inline in the top bar, width: auto, and links are as tall as the bar so the underline touches its bottom border.
  • Links never wrap their label (white-space: nowrap); four short nouns always fit at 360px.
  • At 200% zoom the row scrolls horizontally inside the nav instead of the page scrolling (reflow, WCAG 1.4.10).

Theming

Text is --color-fg-muted (hover and current: --color-fg-default); the underline is --color-brand; the pill is --color-status-requested with --color-on-status text, which stays dark in both themes because yellow is light in both.

/* Thicker current-page marker for a high-visibility theme */
[data-theme="partner"] .app-nav__link[aria-current="page"]::after { height: 3px; }

Accessibility

Role and pattern

A <nav> landmark containing links; the current link uses aria-current="page". This follows the WAI Disclosure Navigation guidance in its simplest form: no menubar roles, no arrow-key handling, because every destination is a plain link.

Keyboard

KeyAction
Tab / Shift+TabMoves between links in order.
EnterFollows the link. Space scrolls the page, as for any link.

Focus

The shared focus ring on :focus-visible (2px, offset 2px). The ring is drawn on the link box, not just the underline, so it stays visible on the current page.

Labelling

The nav is labelled "Main" so it can be told apart from settings navigation and the pagination landmark. The count pill contains a visually-hidden " pending" so the link reads "Requests 4 pending". Do not put the count in aria-label: it would replace the visible name.

Link on surface

Motion

Hover colour transitions over --duration-fast. The underline appears without animation, so there is nothing to disable for reduced motion.

Touch

44px tall on phones (--target-comfortable), 12px horizontal padding. The row scrolls by touch when narrow.

Content

  • One-word nouns, sentence case: Calendar, Year, Requests, Settings.
  • The pill shows an integer only; cap display at 99+ if the team ever grows past it.
  • Hide the pill at zero instead of showing "0".
  • Never add icons to the links: with four short labels they add width and no meaning.
