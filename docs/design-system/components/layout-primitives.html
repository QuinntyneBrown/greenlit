Layout primitives

Layout primitives are the small classes that compose pages: shell, container, stack, cluster, grid, page title row, toolbar row and section.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Greenlit pages are composed, not templated. A handful of single-purpose classes handle width, spacing and alignment so components never carry layout. .shell (and .container) set the page width and gutters; .stack spaces things vertically; .cluster lays things out in a wrapping row; .grid uses the 4, 8 or 12 column grid; .page-header and .page-title-row head a page; .toolbar-row spreads controls; .section separates blocks.

Use these before writing page CSS. Do not use them as visual styling (colour, border): that belongs to card and the other surfaces. See Layout for the grid tokens and Spacing for the scale.

Anatomy

  1. Shell.shell: full width up to --layout-container-max, centred, 16px gutters (24px from 768px). main.shell adds vertical padding.
  2. Page title row.page-title-row: wrapping flex row, title left, controls right, 16px gap.
  3. Stack.stack: vertical flow with 16px gap; --sm 8px, --lg 32px.
  4. Toolbar row.toolbar-row: flex row with space-between, wraps with a 12px gap.

Sizes

Spacing and width come from tokens, not from sizes of the primitive itself.

  • Stack gap: --space-2, --space-4 (default), --space-8.
  • Container: --layout-container-max (1400px at 87.5rem) or --narrow (42rem); copy width --layout-measure (65ch).
  • Gutters and margins: --layout-gutter and --layout-margin: 16/24/32 and 16/32/48 across the three breakpoints.

States

Not applicable: layout primitives are inert containers and have no interactive states; themes only change the tokens of components inside them.

Responsive behaviour

  • Breakpoints (min-width): 40rem (640px), 48rem (768px), 64rem (1024px), 80rem (1280px), 96rem (1536px). Components use 40, 48 and 64 rem.
  • Grid columns: 4 below 768px, 8 from 768px, 12 from 1024px; gutter 16, 24, 32px; margin 16, 32, 48px (--layout-columns, --layout-gutter, --layout-margin).
  • .shell gutters: 16px, then 24px from 768px; main.shell vertical padding 32px, then 40px from 768px.
  • .page-title-row, .page-header, .toolbar-row and .cluster wrap, so controls drop under the title instead of overflowing at 360px.
  • .sidebar-layout becomes two columns (--layout-sidebar-width, 16rem, plus content) from 1024px; below it is one column.
  • .settings-layout adds a 12.5rem column from 1024px (see settings navigation). .form-grid--2 / --3 become 2 / 3 columns from 640px.

Theming

Primitives carry no colour. They read spacing and layout tokens only, so a re-skin changes the scale in one place.

:root { --layout-container-max: 75rem; --layout-gutter: var(--space-5); }

Accessibility

Role and pattern

Layout primitives are structure, not widgets. The page follows the landmark structure: <header> (top bar), <nav>, <main id="main" class="shell">, <footer>. Visual order must equal DOM order: do not use order or grid placement to move content away from its reading position (the one exception, the app nav's second row on phones, is still after the logo and before the account menu in meaning).

Keyboard

KeyAction
TabFollows the DOM order, which the stack, cluster and grid preserve.
Shift+TabReverse; no trap anywhere in layout.

Focus

Containers are not focusable. Ensure overflow: hidden on an ancestor never clips a child's focus ring; the sheet's .grid-card scrolls (overflow-x: auto) and uses negative outline offset for cells for that reason.

Labelling

Landmarks: one <main> per page; repeated <nav>s have distinct aria-labels. A page-level section gets its heading via aria-labelledby. Headings are nested without skipping: one h1 per page.

Motion

Layout does not animate; changes at breakpoints are instant. scroll-behavior: smooth is disabled under reduced motion.

Touch

Keep at least 8px between adjacent tappable items; .cluster gives 12px and .stack 16px. Reflow works down to 320px CSS width and at 400% zoom without two-dimensional scrolling (the sheet's own horizontal scroll is the one exception, WCAG 1.4.10).

Content

  • Page title is the h1, once; section titles are h2.
  • Keep prose to --layout-measure (65ch).
  • Use the primitives rather than margins on components.
  • Gap between sibling blocks: .stack default; between sections: .section.
