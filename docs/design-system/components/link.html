Link

A link goes somewhere: another page, another section, a mailto. It is an anchor with a real href, underlined so it never relies on colour alone.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Use a link for navigation: to another screen, to a person's page, to a field that has an error, to the sign-in page. If the control changes something on the current page (saves, opens a dialog, toggles) it is a button, even when it should look like text (.btn--link).

Greenlit has four link forms: the inline link inside running text and the auth forms, the back link (an arrow plus the parent screen's name, see breadcrumb and back link), identity links (a member's name inside a list or table, quiet until hovered), and auth links (a row of "Forgot your password?" / "Back to sign in" links under an auth card button). Menu entries that navigate are menu items; primary navigation is app navigation.

Anatomy

  1. Link textDescribes the destination out of context ("Ask your manager for an invitation"). Underlined in --color-fg-link, 1px thick.
  2. UnderlineOffset 0.15em; thickens to 2px on hover together with the colour change to --color-fg-link-hover. It is the non-colour cue (WCAG 1.4.1).

Sizes

Not applicable: Links inherit the size of the text or control they sit in; there are no size variants.

States

Links have default, hover, focus and visited-agnostic styling: Greenlit does not style :visited. There is no disabled link: a destination the user may not reach is plain text with an explanation, or is left out. Hover cannot be forced with a data-state hook in the shipped CSS (see drift), so the hover column below reproduces the hover tokens by hand.

  • Current page: a link to the page you are on carries aria-current="page". In navigation components that attribute is also what styles it.
  • External or file links say so in the text ("Download CSV"), never rely on an icon alone.

Responsive behaviour

  • Links wrap with their text; never white-space: nowrap a link inside a paragraph.
  • .auth-links is a wrapping flex row (justify-content: space-between): at 360px two links drop onto separate lines, left-aligned, with a --space-2 row gap.
  • .back-link has a 24px minimum height (--target-min); on phones place it with a full-width row above the page title so the thumb has room around it.
  • Inline links in dense text keep at least 24px between adjacent targets or sit in a line box tall enough to meet WCAG 2.5.8 spacing.

Theming

Colour comes from --color-fg-link and --color-fg-link-hover; muted forms use --color-fg-muted and --color-fg-default. In the dark theme the link tokens lighten so contrast on the dark surface is preserved. To re-skin all links, change the two tokens; do not restyle a per component.

:root { --color-fg-link: var(--palette-blue-700); }
[data-theme="dark"] { --color-fg-link: var(--palette-blue-300); }

Accessibility

Role and pattern

Native <a href> (APG Link). Anchors without an href, <span>s with click handlers and role="link" on a div are not links.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the link.
EnterFollows the link. (Space scrolls the page; it does not activate links.)
Skip linkThe first link on every page jumps to #main; see skip link.

Focus

The global ring appears on :focus-visible: --focus-ring-width in --color-focus-ring, offset --focus-ring-offset, radius --radius-sm. Focus is never removed with outline: none without a replacement.

Labelling

Link text is its name and must make sense out of context: "Back to sign in", not "Click here". Two links with the same text must go to the same place. A back link names the destination ("Calendar"), the arrow is aria-hidden. Links that open another site or download a file say so in the visible text.

Motion

The hover change (colour and underline thickness) is instant. No transition.

Touch

Inline links inherit the text line height. The back link and auth links reach the 24px minimum; navigation links in the top bar and settings navigation use 44px rows. Do not pack inline links closer than their line height.

Content

  • Link text names the destination or the action's result: "Forgot your password?", "Back to sign in", "Ana Ruiz". Never "here" or "read more".
  • A back link repeats the parent screen's title ("Calendar", "Team settings"), not "Back".
  • Sentence case, no trailing punctuation inside the link; punctuation after it stays outside the anchor.
  • Put links inside a sentence only when the sentence still reads without them.
