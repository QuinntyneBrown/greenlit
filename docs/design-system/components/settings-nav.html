Settings navigation

Settings navigation is the in-page list of anchors that jumps between the sections of the Settings screen.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

.settings-nav is a vertical list of in-page links (Team, Allowances, Work week & holidays, Coverage, Notifications) shown in a sticky left column on wide screens, next to the long .settings-content column. The sections are real headings on one scrolling page, so the links are anchors, not tabs.

Use it only for one long page with five or so sections. For switching between views use tabs; for moving between screens use the app navigation. Below 1024px it is hidden and the page is simply read down, because the sections are short.

Anatomy

  1. Anchor list<nav aria-label="Settings sections"> with a ul of links to section ids, 2px gaps.
  2. LinkBlock link with 8px by 12px padding, body-small text, muted; hover shows a subtle fill and darker text.

.settings-nav__off is a muted note shown in place of links that the signed-in role does not have (for a member the manager-only sections disappear instead).

Sizes

Not applicable: a single body-small size.

States

Hover is a real pseudo-class on .settings-nav a (no forced hook); focus is forced via data-state="focus". The link being scrolled to uses aria-current="location" when the page highlights it (the kit has no separate style for it today).

Responsive behaviour

  • Below 1024px (--layout-breakpoint-lg) the nav is display: none; the page is a single column read from the top.
  • From 1024px the page becomes a two-column grid, 12.5rem for the nav and the rest for the 48rem-wide content; the nav is position: sticky; top: 6rem so it follows the reader.
  • Section headings use scroll-margin-top: 6rem so the sticky top bar does not cover the heading after a jump.
  • If a phone needs to jump between sections, add a select in the page rather than showing the sidebar.

Theming

Text --color-fg-muted, hover fill --color-bg-subtle. There is no dark rule; all values are semantic.

.settings-nav a[aria-current="location"] { background: var(--color-accent-subtle); color: var(--color-fg-accent); }

Accessibility

Role and pattern

A <nav> landmark of in-page links. This is a list of same-page anchors, not the APG Tabs pattern; do not give it role="tablist".

Keyboard

KeyAction
Tab / Shift+TabMoves between links.
EnterScrolls to the section and moves focus to it (give section headings tabindex="-1" if focus must land there).

Focus

Shared ring on :focus-visible. Because the nav is sticky it remains in view while the reader tabs through the form below.

Labelling

The landmark is named "Settings sections" so it is distinct from the main navigation. Each link's text matches its section heading exactly.

Contrast

Link on canvas
Hover text on subtle fill
Focus ring on canvas

Motion

Anchor jumps use scroll-behavior: smooth, disabled under prefers-reduced-motion.

Touch

Hidden on touch-sized screens. On large tablets each link is 36px tall, above the 24px WCAG minimum, with 2px gaps.

Content

  • Link text equals the section heading: "Work week & holidays".
  • Five sections maximum; more means the page should be split.
  • Order follows the page, top to bottom.
