Textarea

A textarea takes free text that needs more than one line: a reason for declining a request, a note on a time-off request.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Use a textarea when the answer is a sentence or more and may wrap: the optional reason when a manager declines a request, a note with a new request. For a name, e-mail or number use a text field.

The textarea shares every visual rule with the text field (one rule styles .input, .select, .textarea), adding a minimum height of two and a half rows and vertical resize. It always sits in a form field; when there is a limit, show a live .field__counter below it.

Anatomy

  1. Label with optional marker.field__label plus .optional in subtle text when the field can be left empty.
  2. Text area.textarea: full width, minimum 100px (--control-height-md × 2.5), resizes vertically only.
  3. Help textSays who reads the text and what happens if it is empty.

Variants

One variant. A character limit adds a live counter.

32 of 200 characters
A .field__counter right-aligned under the field. Announce it politely only at meaningful thresholds, not on every keystroke.
HTML
<div style="width: 100%; max-width: 24rem;"><div class="field"><label class="field__label" for="ta-v1">Note to your manager <span class="optional">(optional)</span></label><textarea class="textarea" rows="3" id="ta-v1" name="ta-v1" aria-describedby="ta-v1-count" maxlength="200">Covering Ben on the launch week.</textarea><span class="field__counter" id="ta-v1-count">32 of 200 characters</span></div></div>

Sizes

Not applicable: A textarea has one size: full width of its field and at least 100px high. Make it taller with the <code>rows</code> attribute; users can resize it vertically.

States

States match the text field: forced data-state hover and focus for review; real aria-invalid, disabled and readonly.

ControlDefaultHoverFocusDisabledInvalidRead-only
Textarea

Both themes

  • Entered text and the placeholder differ in colour (--color-fg-default vs --color-fg-subtle) so a value is never mistaken for a hint.
  • The resize handle is the browser's; it is kept so users with long notes can enlarge the box.

Responsive behaviour

  • Full width of the field at every breakpoint; in a two-column grid give a textarea its own row (grid-column: 1 / -1).
  • The minimum height means it never collapses to one line on a phone. Keep rows between 3 and 6; for more, move the writing to its own screen.
  • Resize is vertical only, so the box cannot be dragged wider than a 360px viewport.

Theming

Identical tokens to the text field: --color-bg-surface, --color-border-strong, --color-fg-default, --color-fg-subtle, --color-focus-ring, --color-danger-solid. Re-skin once through those tokens and all three controls follow.

/* Monospace for pasted import data */
.textarea--code { font: var(--text-code); }

Accessibility

Role and pattern

Native <textarea> with a visible <label for>. No ARIA role is needed. A character limit is communicated with maxlength and a counter linked through aria-describedby.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to and from the field (Tab does not insert a tab character).
EnterInserts a new line; it does not submit the form.
Ctrl+EnterMay submit in a dialog; say so in help text if you add it.
Arrow keys, Home, EndNative caret movement and selection.

Focus

Fields draw the same ring as every control, but inside the border: --focus-ring-width solid --color-focus-ring with zero offset, plus a border in the ring colour, so the focused edge is at least 3:1 against both the field and the page. The ring is shown for :focus-visible, which for text fields is every focus, pointer included.

Labelling

Visible label plus aria-describedby pointing at the help text (and the counter or error). The optional marker is part of the label text so it is read. Errors set aria-invalid="true" and link a .field__error.

Contrast

Text on field
Placeholder on field
Border on page
Counter text on page
Focus ring on field

Motion

Border colour transitions over --duration-fast; nothing else moves.

Touch

The box is at least 100px high and full width, so the target is large. Do not rely on the resize handle on phones: set sensible rows.

Content

  • Label with a noun: "Reason", "Note". Mark optional fields with "(optional)".
  • The placeholder is an invitation in the product's voice ("Let Ana know why"), naming the reader.
  • Help says who sees the text and what a blank value means.
  • Counters read "32 of 200 characters" and become an error only when the limit is exceeded.
