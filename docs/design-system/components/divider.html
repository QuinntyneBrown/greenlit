Divider

A divider is a hairline rule that separates groups without adding a container.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

The divider is a one-pixel rule in --color-border-default: the hr element (or .divider), .menu__divider between menu groups, and the borders that other components draw themselves (.card__footer, .dialog__footer, .drawer__header, .settings-section). It is horizontal only.

Use it to separate two groups inside a surface. If whitespace alone separates them, use whitespace. If the groups deserve a heading, use a .section-title and spacing. If a group needs a frame, use a card. Never use it to fake a table row; use a table.

Anatomy

  1. Rule1px solid --color-border-default, no height; vertical margin --space-6 on hr unless overridden.

or
Auth divider. .auth-divider is the labelled rule between two ways in on an auth card (password form, then "or", then Continue with Google). The label sits in the rule; role="separator" with aria-label names it.
HTML
<div class="auth-divider" role="separator" aria-label="or" style="width: 100%; max-width: 24rem;"><span>or</span></div>

Sizes

Not applicable: a divider is always one pixel; spacing around it is set by the surrounding layout.

States

A divider is not interactive and has no states.

Responsive behaviour

  • Full width of its container at every width.
  • Margins are vertical only; there is no inset variant.
  • In dense areas (menus) use .menu__divider to keep the 4px rhythm.

Theming

Only --color-border-default. In dark it becomes a green-grey hairline; in forced-colours mode it maps to CanvasText so it stays visible.

hr { border-top-color: var(--color-border-strong); }  /* stronger rules in a high-contrast theme */

Accessibility

Role and pattern

The native <hr> has the implicit separator role. Inside a role="menu" a separator is valid APG menu content. For a purely visual rule drawn with CSS (a border), no role is needed.

Keyboard

KeyAction
TabDividers are not focusable and are skipped.
Arrow keys in a menuSkip over the separator between items.

Focus

A divider never receives focus.

Labelling

No label. Do not use a divider as the only cue of a grouping: pair it with a heading or aria-labelledby region when the groups are distinct.

Contrast

Divider on surface (decorative, exempt)
Strong border on surface (inputs)
Text on surface

Motion

None.

Touch

Not a target. Keep at least 8px between a divider and a tappable row.

Content

  • Dividers carry no text; if a label is needed, use a heading.
  • Do not stack dividers or put one directly beside a border.
  • Menu groups: account items, then a divider, then Sign out.
