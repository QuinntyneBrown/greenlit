Closure list

The closure list shows a team's school closures in Settings → School calendar (L2-061, L2-062): the label, the dates, whose calendar it is, "Imported" for rows a calendar file added, and Edit and Delete for the manager.

WCAG 2.2 AAStatus: stableSince v1.2

  • Anatomy
  • States
  • Responsive behaviour
  • Accessibility
  • Content

  • Sources

Overview

Use it only in the School calendar section. A member sees the same rows without actions. Each action opens a dialog; nothing is edited inline.

  • PA dayFri 20 Nov 2026 · All children
  • Winter breakMon 21 Dec 2026 – Fri 1 Jan 2027 · Leo ChenImported

Anatomy

  1. .closure-list: bordered list, like .team-list.
  2. .closure-list__icon: the school icon, decorative.
  3. .closure-list__what with .closure-list__label and .closure-list__meta (dates · "All children" or a name).
  4. An optional badge "Imported".
  5. .closure-list__actions: "Edit" and "Delete" small buttons, end-aligned.

States

Default; read-only (no actions) for a member; empty, which is the empty state "No closures yet" with "Add a closure" and "Import a calendar".

Responsive behaviour

Rows wrap: below 30rem the actions move under the label; the dates never wrap mid-range.

Accessibility

  • The list is named "School closures".
  • Buttons carry the closure in their name: "Edit PA day", "Delete PA day".
  • "Imported" is text, not colour.

Content

Dates as "Fri 20 Nov 2026" or a range with an en dash; "All children" or the child's full name.

Code

Angular: rendered by SchoolCalendarSection in the app with the classes above; no separate gl-* atom, since only one screen uses it.
