Component · Sheet and brand

Month mini

A small calendar month, seven columns wide, with each day coloured by status: used on the person page to show one member's whole year as twelve of these.

Overview

The month mini (.month-mini-grid of .month-mini__days) is a conventional month calendar in miniature: title, Monday-first weekday initials and a numbered square for each day. It shows one person's days through the same status colours as the sheet cell, with today circled by a ring.

Use it for a single person's year (the person page: twelve months in a responsive grid, with a legend) and for the printed summary. It is read-only: to change a day go to the team grid. Do not use it for choosing dates (use a date picker) or for the team (use the year grid).

Anatomy

  1. Title.month-mini__title: the month name as an <h3>.
  2. Weekday heads.mini-head: M T W T F S S, aria-hidden, in a 7-column grid with --space-1 gaps.
  3. Day.mini-day[data-status]: square (aspect-ratio: 1), the date number in tabular figures, role="img" with a name.
  4. Today ringaria-current="date" adds a 2px ring: a surface-coloured gap then a 2px --color-fg-default ring.

Variants

Days come in five statuses plus the today ring. A holiday is off with its name in the label.

Sizes

Not applicable: the mini month has one size: the 7-column grid fills its column and each square is as wide as the column divided by seven.

Responsive behaviour

  • .month-mini-grid is a single column on phones (--space-5 padding), two columns from --layout-breakpoint-sm (40rem), four from --layout-breakpoint-lg (64rem) with --space-8 padding.
  • Each day is a square: at 360px a month is about 18rem wide, so a day is about 36px; in four columns on a 1280px screen it is about 38px.
  • The month never scrolls horizontally: seven columns is always the layout. Use it where the team grid would force scrolling and a single person's days are enough.
  • There are no touch targets: days are not interactive. Tapping a mini day does nothing.

Theming

A mini day reads --status-bg (status tokens), --color-on-status for the number on a status, --color-fg-muted on empty/off days, --color-fg-subtle for weekday heads, and --color-bg-surface plus --color-fg-default for the today ring. Off days use off-soft, a translucent coral, so they stay quiet in a dense picture.

.person-year { --color-status-off-soft: var(--color-status-empty); }  /* mute weekends further */

Accessibility

Role and pattern

A static image-like calendar: the container is a heading (<h3>) followed by seven-column markup; each day is role="img" with a full-date name. It is not an ARIA grid because nothing is interactive, so it adds no tab stops. If a future version makes days interactive, convert to the grid pattern in team grid.

Keyboard

KeyAction
TabDoes not enter the month; there is nothing to focus.
H (screen reader)Navigates between month headings, a quick way across the twelve months.

Focus

Nothing to focus. If days link out later, use the shared focus ring with a 2px offset so the ring does not touch the today ring.

Labelling

Each day reads "9 July: Confirmed" (or "15 July: Company day" for holidays, "13 July: Requested"). Weekday initials are aria-hidden because each day's name already has the date. Today's name adds "today" in practice (aria-current="date" is announced by most screen readers). Unlike the sheet cell there is no glyph in a mini day; the name and the number are the non-colour carriers, so keep the label.

Touch

Not a touch target. Keep each day at least 24px square in case it becomes a link; at one column on a 320px phone each day is about 32px.

Content

  • Month titles are full English month names ("July") in an h3; the year is in the page heading, not repeated per month.
  • Weeks start on Monday (M T W T F S S), matching the team sheet.
  • Day names: " : "; holidays use the holiday name instead of "Not working".
  • The legend above the months names the colours: Confirmed, Requested, Tentative, Weekend / holiday.

  • The person page legend uses data-status="off-soft" for its swatch while the calendar legend uses off; both are valid, matching what each view draws.
