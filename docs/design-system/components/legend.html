Component · Sheet and brand

Legend

The key to the sheet's colours: a row of small swatches with their names, placed directly above the view that uses them.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

The legend (.legend, a list of .legend__item each with a .swatch) names the four colours of the sheet: Confirmed (green), Requested (yellow), Tentative (blue) and Weekend / holiday (red). It sits above the team grid, the month mini and the year view, next to the helper text.

The same .swatch also appears inside the paint picker (segmented control) and on selection bar buttons to say what a button will paint. The legend explains; it is not a filter. For a clickable filter use chips.

  • Confirmed
  • Requested
  • Tentative
  • Weekend / holiday
The four-colour calendar legend.
HTML
<ul class="legend" aria-label="Legend"><li class="legend__item"><span class="swatch" data-status="confirmed" aria-hidden="true"></span>Confirmed</li><li class="legend__item"><span class="swatch" data-status="requested" aria-hidden="true"></span>Requested</li><li class="legend__item"><span class="swatch" data-status="tentative" aria-hidden="true"></span>Tentative</li><li class="legend__item"><span class="swatch" data-status="off" aria-hidden="true"></span>Weekend / holiday</li></ul>

Anatomy

  1. Swatch.swatch[data-status]: 0.75rem square, --radius-xs, filled from --status-bg. aria-hidden.
  2. Label.legend__item text in caption size and --color-fg-muted, never wrapped inside an item.
  3. Listul.legend with aria-label="Legend"; items wrap to a new line with --space-1 row gap and --space-4 column gap.

Sizes

Not applicable: the swatch is a fixed 0.75rem square and the label uses the caption role; there is no size scale.

  • Loading: the legend is shown immediately (it does not depend on data); only the paint control is disabled in the loading mock.

Responsive behaviour

  • The list is display: flex; flex-wrap: wrap: on one row at 480px and wider, two rows on a 360px phone. The toolbar row (.toolbar-row) puts the hint text beside it and wraps it below.
  • Never scroll or truncate a legend; if it does not fit it wraps.
  • The legend stays above the grid (not in a sticky region) so it scrolls away with the page header. The grid itself carries state in glyphs and names.
  • Touch: the legend is not interactive; no target-size requirement. If swatches ever became buttons, the swatch must grow to 24px.

Theming

The swatch resolves the status tokens, so its colour tracks the theme with the cells. Label colour is --color-fg-muted. To add a custom status colour for another product mode, extend the attribute selector and reuse the legend unchanged:

[data-status="holiday"] { --status-bg: var(--color-status-off); }

Accessibility

Role and pattern

A plain list: <ul class="legend" aria-label="Legend"> with one <li> per status. Swatches are aria-hidden; the visible text is the content, so the legend is fully readable without colour. It is not a widget, so there are no roles.

Keyboard

KeyAction
TabThe legend has no focusable elements and is skipped.
↓ (screen reader browse)Reads the list item by item: "list, 4 items; Confirmed; Requested; …".

Focus

No focusable parts, so no focus style. Do not add a tabindex.

Labelling

The list is named "Legend". Item text is the status word exactly as it appears in cell names (Confirmed, Requested, Tentative) so the legend and the grid agree; the fourth item is "Weekend / holiday", which a cell reads as "Not working". The legend does not repeat the glyphs; mention them in the hint or in help text if needed (✓ confirmed, … requested, ? tentative).

Motion

No motion.

Touch

Not interactive. The text is 12px (caption), which is small but inside the legible range because it is supplemental; keep the grid cells' glyphs and names as the primary carrier.

Content

  • Names are the status words only: Confirmed, Requested, Tentative; the red swatch is "Weekend / holiday". Don't write "Approved" or "Pending".
  • Order always goes Confirmed, Requested, Tentative, Weekend / holiday (most to least settled, then the rule-based colour).
  • Sentence case; no trailing punctuation; no colour words in the label ("Green").
  • Hint text beside it is a sentence: "Click or drag across your own row to request time off."
