Spinner

A spinner shows that something short is happening and the app has not frozen: a ring in two sizes, the busy button, and the banner spinner.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Use a spinner for a wait of a few seconds when the length is unknown and the area is too small for a skeleton or a progress bar: a busy button, a reconnecting banner, a small inline refresh. It says "working", nothing more.

Do not use a spinner as the page loading state (use skeletons that keep the layout), for waits you can measure (use a progress bar) or as decoration. Show it only if the wait passes about 300ms, to avoid a flash.

Anatomy

  1. RingA bordered circle in --color-border-default whose top segment is --color-accent; it spins at 0.8s per turn.
  2. Accessible namerole="status" plus an aria-label (or visible text beside it); the ring itself is visual only.

Variants

Standalone

Loading the calendar…
The default ring is the shipped variant. Give it a name with aria-label, or put a visible message beside it and hide the ring from assistive technology.
HTML
<span class="spinner " role="status" aria-label="Loading"></span><span class="text-sm text-muted">Loading the calendar…</span>

On a button

aria-busy="true" on a button draws a spinner over a transparent label, keeps the button width and blocks clicks. This is the only spinner most screens use.
HTML
<button class="btn btn--primary" type="button" aria-busy="true">Request days</button><button class="btn btn--approve" type="button" aria-busy="true">Confirm</button><button class="btn" type="button" aria-busy="true">Cancel</button>

In a banner

Reconnecting…
Hang on while we check your connection.
.banner .spinner sizes the ring to 1rem to sit in the banner's icon slot. See alert and banner.
HTML
<div class="alert banner" style="width: 100%;"><span class="spinner " role="status" aria-label="Checking connection"></span><div class="alert__body"><div class="alert__title">Reconnecting…</div><div>Hang on while we check your connection.</div></div></div>

Sizes

Two sizes. The default is 1.25rem (20px) with a 2px ring; .spinner--lg is 2.5rem (40px) with a 3px ring. In a banner the ring is 1rem. Pick the smaller size inside controls and the larger when it is the only thing in an empty region.

1rem (banner), 1.25rem (default), 2.5rem (.spinner--lg).
HTML
<span style="width: 1rem; height: 1rem;" class="spinner " role="status" aria-label="Small, in a banner"></span><span class="spinner " role="status" aria-label="Default"></span><span class="spinner spinner--lg" role="status" aria-label="Large"></span>

States

A spinner has one state: spinning. The states that matter are around it: appearing, replaced by the result, and failing.

ElementIdleBusyDoneFailed
Button Team settings saved Couldn’t save

Both themes

  • Appearing: delay the spinner about 300ms so quick actions do not flash it.
  • Done: remove the spinner and say what happened in a live region and next to the control.
  • Reduced motion: the spinner keeps spinning (the global rule shortens duration but keeps one iteration at 0.01ms, so the ring would stop). Where the ring stops, the busy state must still be readable: keep the visible "Saving…" text.

Responsive behaviour

  • The ring is a fixed size in rem and never scales with the viewport.
  • A busy button keeps its exact width at every breakpoint, so a full-width .btn--block on a phone does not jump when it starts.
  • Centre a large spinner in its region with flex or grid; do not position it absolutely over content that is still interactive.
  • A banner spinner wraps with the banner text on narrow screens (title and message stack).

Theming

The ring uses --color-border-default for the track and --color-accent for the moving segment, so it follows the theme: a dark ring in the light theme, a light ring in the dark theme. A busy button recolours the spinner to the button's own foreground so it stays visible on primary, danger and approve backgrounds.

.spinner { border-color: var(--color-border-default); border-top-color: var(--color-accent); }

Accessibility

Role and pattern

A spinner is a live status: role="status" with a text alternative (WAI-ARIA status role). When the ring sits beside a visible message ("Saving…"), hide the ring with aria-hidden="true" and put role="status" on the message. For a busy region, set aria-busy="true" on the region being updated. A busy button keeps its name and sets aria-busy="true".

Keyboard

KeyAction
TabA spinner is not focusable. A busy button remains in the tab order but ignores activation.
EscNot handled. Offer a Cancel button for waits longer than a few seconds.

Focus

Never move focus onto a spinner. When a button becomes busy it keeps focus (it is not disabled, so focus is not lost); when the operation ends, leave focus where it is or move it to the result if the control was removed.

Labelling

Name what is happening, not that something is spinning: "Checking connection", "Saving settings". Announce the end of the wait in the same live region: "Team settings saved". Do not use "Loading" alone when a more precise word exists.

Motion

The ring rotates once per 0.8s, linear, forever. Under prefers-reduced-motion: reduce the global rule limits animation to a single 0.01ms iteration, which stops the rotation; the spinner then reads as a static partial ring. Because motion is the signal, always pair the spinner with a visible text status so the busy state does not depend on movement (WCAG 2.2.2: a spinner that lasts under 5 seconds is exempt, a longer wait needs a pause or a stop).

Touch

The spinner is not a target. A busy button keeps its 40px (medium) height and ignores presses, so a double tap cannot submit twice.

Content

  • Pair every spinner with a status in words: "Saving…", "Checking connection…". Use an ellipsis character, not three dots.
  • Do not change a busy button's label; keep "Save settings" and announce progress in a live region.
  • On completion replace the spinner with the result in words and an icon, not just by removing it.
  • If the wait could pass ten seconds, replace the spinner with a progress bar or add a Cancel action.
