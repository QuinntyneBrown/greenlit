Component · Inputs

File field

The file field lets a person choose one file with a real input type="file" styled as a small button, and shows the chosen file's name beside it (L2-062).

WCAG 2.2 AAStatus: stableSince v1.2
  • Overview
  • Anatomy
  • States
  • Responsive behaviour
  • Accessibility
  • Content
  • Code
  • Sources

Overview

Use it inside a form field with a label and help text saying what files are accepted and how big they may be.

Calendar file
No file chosen
Up to 1 MB. All-day events become closures.

Anatomy

  1. .file-field__button: a .btn--sm label wrapping the transparent .file-field__input, so the native control keeps keyboard and touch.
  2. .file-field__name: the chosen file's name with a file icon, or "No file chosen" muted.

States

Empty, chosen, disabled (while busy), and invalid, shown by the dialog's alert ("That file isn't a calendar we can read").

Responsive behaviour

The name wraps anywhere, so a long file name never widens a 390 px dialog.

Accessibility

  • The input is named by the field label and the button text; the help is its description.
  • Focus shows on the button through :focus-within.

Content

"Choose an .ics file"; help "Up to 1 MB. All-day events become closures."

Code

Angular: written in ImportCalendarDialog with these classes.
