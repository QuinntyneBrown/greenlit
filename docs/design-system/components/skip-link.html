Skip link

The skip link is the first focusable element on every page; it appears on focus and jumps over the top bar to the main content.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

.skip-link is an anchor to #main, placed as the first child of <body>. It is parked above the viewport (top: -96px) and slides to top: 16px on :focus-visible, so sighted keyboard users see it and everyone else never does. It satisfies WCAG 2.4.1 (bypass blocks).

Every screen has one, including the bare shell (sign in) where it is harmless. Do not add more skip links; the single target is the <main id="main"> landmark. This documentation site has one too: press Tab once at the top of this page.

Anatomy

  1. LinkRaised surface (--color-bg-surface-raised), medium radius, shadow 3, 8px by 16px padding, default text colour.

Variants

There is one variant. The stage here pins the link in the flow; in a page it is absolutely positioned.

Skip to content
Shown as when focused. Real behaviour: hidden above the viewport until focused.
HTML
<a class="skip-link" href="#main" style="position: static; display: inline-block;">Skip to content</a>

Sizes

Not applicable: a single size: body text with 8px by 16px padding.

States

The state that matters is hidden versus focused. Both are shown below; hidden is simulated by hiding the link visually in the stage.

  • It sits at --z-tooltip so it is above the sticky top bar and the page content when shown.

Responsive behaviour

  • Same at every width: it appears at 16px from the top and left edges of the viewport.
  • It does not take layout space (absolutely positioned), so it never shifts content when focused.
  • On touch devices without a keyboard it is never focused and so never seen; this is expected.

Theming

Surface --color-bg-surface-raised, text --color-fg-default, shadow --shadow-3. Contrast against the page behind it comes from the shadow plus the surface, and the text pair is checked against its own surface.

.skip-link { border: 1px solid var(--color-border-strong); }  /* stronger edge on busy backgrounds */

Accessibility

Role and pattern

A plain in-page anchor, <a href="#main">, as recommended by WCAG technique G1 (a link at the top of the page to the main content). No ARIA. The target <main id="main"> receives focus by the browser's fragment navigation.

Keyboard

KeyAction
TabFirst stop on the page; the link slides into view.
EnterMoves focus to #main; the next Tab lands on the first control inside it.
Tab againLeaves the link; it slides out again.

Focus

The shared focus ring applies on top of the revealed link. Because the link only shows on :focus-visible, a mouse click on an unseen link cannot happen.

Labelling

Visible text "Skip to content" is the name. Keep it identical on every page so users can learn it.

Contrast

Text on raised surface
Focus ring on raised surface
Hover text on raised surface

Motion

The top property transitions over --duration-fast. Under reduced motion the link jumps into place.

Touch

Not a touch feature, but when it is shown (external keyboard on a tablet) it is 40px tall with 16px padding.

Content

  • "Skip to content" on every page, in sentence case.
  • Do not add "main" to the text: "Skip to main content" is acceptable only if used everywhere.
  • Do not translate it into an action ("Go to calendar"); the target is the page's main region, whichever it is.
