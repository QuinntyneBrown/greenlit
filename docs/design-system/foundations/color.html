Overview

Greenlit is a calm, green-accented tool whose colour has a job: the sheet. Neutral grey-greens carry the interface, one green carries the brand, and four saturated colours carry meaning on the sheet. Everything else (information, success, warning, danger) is a tint with an icon and text.

Sheet status colours

The sheet has four colours with fixed meanings, and the same meaning everywhere: in the grid, the year view, the legend, the selection bar and the person page. Text drawn on a status colour is always ink (--color-on-status), so every pair clears 4.5:1 in both themes.

Translucent tints (--color-status-off-soft, --color-status-empty) are composited over the canvas by hand: day numbers on them measure 10:1 to 15:1 in both themes.

Usage

  • Components read semantic tokens (--color-*), never primitives. Only tokens.css touches --palette-*.
  • Never state meaning by colour alone: pair it with a glyph, text or an accessible name (WCAG 1.4.1). Every status in the product has one.
  • Text and icons need 4.5:1 (3:1 for large text and icon-only UI); input edges and focus rings need 3:1.
  • The dark theme is built from roles, not inverted: surfaces lighten as they rise, the accent flips to near-white, status colours lighten slightly.
  • A brand theme is one [data-theme="name"] block that overrides semantic tokens only. Add its pairs to contrast-pairs.json and re-run the checker.
  • Never write a hex value in a component or a page. The checker rejects raw colour literals outside tokens/.
