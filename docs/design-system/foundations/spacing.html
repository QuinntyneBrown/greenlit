Spacing

A 4px scale from 0 to 96px, and the rules for what goes inside a component and what goes between them.

WCAG 2.2 AAStatus: stable
  • Overview
  • The scale
  • Inside and between
  • Usage
  • Tokens

Overview

One scale for padding, gaps and margins. If a value is not on the scale it is a mistake or a deliberate optical adjustment, never a new token.

Inside and between

WhereInside the componentBetween components
Small control (32px)--space-3 horizontal, --space-1 icon gap--space-2
Medium control (40px)--space-4 horizontal, --space-2 icon gap--space-3 in a cluster
Card, dialog body--space-6--space-4 between stacked cards
Form--space-1 label to control--space-4 between fields, --space-8 between sections
Page--layout-margin at the edge--space-8 to --space-12 between sections

Usage

  • Everything snaps to the 4px base. The mocks had a handful of off-grid values (0.1rem, 0.28em, 0.35em); they are optical adjustments inside the logo and badge dots, kept out of the scale and logged as drift in the README.
  • Inside a component use --space-6 or smaller; between components use --space-6 or larger.
  • Use gap (.stack, .cluster, grid gap) rather than margins on children, so reordering never breaks spacing.
  • The sheet is the exception: cells sit --space-0-5 (2px) apart because density is the point, and the cell is --cell-height tall.
