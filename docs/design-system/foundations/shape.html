Foundation · Shape

Shape

Six radii that grow with element size, and two border widths.

WCAG 2.2 AAStatus: stable
  • Overview
  • Radii
  • Border widths
  • Tokens

Overview

Radius grows with the size of the thing: the smaller the element, the smaller the corner. Nested elements use a radius one step smaller than their container.

Radii

TokenUsed by
--radius-xsCheckboxes, swatches, year-grid months
--radius-smSheet cells, date chips, kbd, focus ring default, menu items
--radius-mdButtons, inputs, selects, alerts, menus, toasts
--radius-lgCards, the grid card, tables, selection bar
--radius-xlTop corners of a dialog sheet on phones
--radius-fullBadges, chips, avatars, switches, progress

Border widths

  • --border-width-hairline (1px): card edges, input edges, dividers, the gap between year-grid month slivers.
  • --border-width-thick (2px): the selected state ring on the sheet, the alert accent edge uses 4px (.alert, .form-summary) as a fixed decorative rule.
