Foundation · Layout

Layout

Five breakpoints, 4/8/12 columns, gutters and margins that grow with the viewport, and the four page templates.

WCAG 2.2 AAStatus: stable

Overview

Layout is mobile-first: base styles are the 360px phone, and min-width media queries add room. The wide sheet scrolls inside its own card; the page never scrolls sideways.

Containers and bars

  • --layout-container-max (1400px) caps the app shell; .shell centres it with --space-4 to --space-6 side padding.
  • --layout-topbar-height is the minimum height of the top bar; on phones the app navigation wraps to a second scrolling row.
  • --layout-sidebar-width is reserved for sidebar layouts; the product currently uses top navigation, so it is documented but unused by pages.
  • --layout-measure caps prose. Control heights (--control-height-sm/md/lg: 32, 40, 48px) and --cell-height (40px) are shared by every control so rows align.
