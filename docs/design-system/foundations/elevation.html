Foundation · Elevation

Elevation

Four shadow levels, the surface hierarchy that carries elevation in dark mode, and the z-order.

WCAG 2.2 AAStatus: stable
  • Overview
  • Shadows
  • Surfaces
  • Z-order
  • Usage
  • Tokens

Overview

Elevation says what floats above what. Shadows do the work in light mode; in dark mode shadows are barely visible, so surface lightness carries it: canvas < surface < raised.

Shadows

shadow-1
shadow-2
shadow-3
shadow-4
TokenLevelUsed by
--shadow-1Cards, primary button on hover, avatar-group rings
--shadow-2Interactive card hover, tooltip
--shadow-3Menus, popovers, toasts, skip link
--shadow-4Dialogs, drawers, the selection bar

Surfaces

Canvas
--color-bg-canvas
Surface
--color-bg-surface
Raised
--color-bg-surface-raised
Sunken
--color-bg-surface-sunken

A dialog is always --color-bg-surface-raised with --shadow-4; a card is --color-bg-surface with --shadow-1 and a 1px border so it still reads on a bright display.

Z-order

TokenValueLayer
--z-base · page content
--z-raised · sticky grid names
--z-sticky · top bar
--z-dropdown · menus, selection bar
--z-overlay · dialog backdrop
--z-modal · dialogs and drawers
--z-popover · popovers
--z-toast · toast region
--z-tooltip · tooltips, skip link

Components never write a raw z-index; they pick a layer. A new layer needs a token and a row here.

Usage

  • Do not stack shadows on shadows: a card inside a dialog has a border, not a shadow.
  • Focus is not an elevation: use the focus ring (--shadow-focus is the box-shadow form for elements that cannot take an outline).
  • Dark theme shadows are stronger and pure black-based (--shadow-color).
