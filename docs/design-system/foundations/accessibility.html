Accessibility

The WCAG 2.2 AA commitments the system makes, how to test them, and what every component page must document.

WCAG 2.2 AAStatus: stable
  • Overview
  • Commitments
  • Testing procedure
  • Component contract
  • Tokens

Overview

Accessibility is part of the design language, not a layer on top. The commitments below are verified by the checkers in this folder and by the e2e suite.

Commitments

  • 1.4.1 Use of colour: no state is carried by colour alone; the sheet's cells carry ✓ … ? and accessible names.
  • 1.4.3 / 1.4.11 Contrast: text 4.5:1 (3:1 large), UI edges and focus rings 3:1; every pair is in contrast-pairs.json and checked in both themes.
  • 1.4.4 / 1.4.10 Resize and reflow: rem sizes, 200% zoom works, no two-dimensional scroll at 360px except inside data cards.
  • 1.4.12 Text spacing: no fixed-height text containers.
  • 2.1.1 Keyboard: every interaction, including painting days and selecting ranges, has a keyboard path.
  • 2.4.7 / 2.4.11 Focus visible and not obscured: one ring everywhere; sticky bars never cover the focused element.
  • 2.5.8 Target size: 24px minimum, 44px for comfortable touch.
  • 3.3.1 / 3.3.3 Errors: errors are text, linked to the field, and say what to do.
  • 4.1.2 Name, role, value: native elements first; ARIA only where a pattern needs it (grid, radiogroup, dialog).
  • 4.1.3 Status messages: toasts and inline results are announced through live regions without moving focus.
  • Motion: prefers-reduced-motion is honoured through tokens.

Testing procedure

  • Tab through the page: order matches reading order, the ring is always visible, nothing is trapped except an open dialog.
  • Operate the sheet with the keyboard only: arrows, Space, Shift+arrows, Esc.
  • Run the contrast checker after any token change.
  • Read a page with a screen reader (NVDA or VoiceOver): every cell announces day, date and status.
  • Switch to dark and to forced colors; zoom to 200%; test at 360px.
  • Playwright asserts roles and accessible names through page objects, so a lost name fails a test.
