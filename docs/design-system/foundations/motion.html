Foundation · Motion

Motion

Five durations and four easings, replayable here, and what happens when a user asks for less motion.

WCAG 2.2 AAStatus: stable
  • Overview
  • Durations
  • Easings
  • Choreography
  • Reduced motion
  • Tokens

Overview

Motion in Greenlit is short and functional. The values below are the whole vocabulary.

Durations

0ms · state that must not lag
120ms · hover, focus, button colour
200ms · menus, toasts in, switches
320ms · dialogs and drawers in
500ms · rare, large movement

Easings

things that move within the screen
things arriving: decelerate
things leaving: accelerate
playful overshoot; not used by the product yet

Choreography

  • Motion explains a change (where did that come from?); it never decorates. If removing it loses nothing, remove it.
  • Enter slower than you leave: dialogs arrive over --duration-slow and leave over --duration-base.
  • Only transform and opacity animate for movement; colour changes use --duration-fast.
  • The sheet never animates a cell while painting; the pointer is the feedback.

Reduced motion

Under prefers-reduced-motion: reduce the tokens set every duration to near zero, so components need no per-component media query. components.css additionally stops the skeleton shimmer and replaces the indeterminate progress bar with a static bar. Spinners keep turning because they are status indicators; they are shown with text for screen readers.

Tokens

TokenLightDark
--duration-instant
--duration-fast
--duration-base
--duration-slow
--duration-deliberate
--ease-standard
--ease-enter
--ease-exit
--ease-spring
