Responsive

Mobile-first rules, what each component does at each breakpoint, and the test matrix.

WCAG 2.2 AAStatus: stable
  • Overview
  • Rules
  • Behaviour by component
  • Testing matrix

Overview

The product is used on phones at least as much as on laptops: members paint days from a phone, managers confirm from a desk. Every screen is designed at 360px first.

Rules

  • Mobile first: base CSS is the 360px layout; min-width queries only add.
  • No horizontal page scroll at 360px. Wide data (sheet, year grid, tables) scrolls inside its own card with sticky identifying columns.
  • Touch: every sheet interaction has a tap path; under (pointer: coarse) small controls grow to --target-comfortable (44px).
  • Never hide a feature at a breakpoint; relocate it (the paint picker scrolls, the selection bar wraps).
  • Breakpoint values come from --layout-breakpoint-*; media queries use the same rem values.
