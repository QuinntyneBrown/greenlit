Foundation · Iconography

Iconography

Twenty-two outline icons on a 24-unit grid, 2px stroke, drawn in currentColor.

WCAG 2.2 AAStatus: stable
  • Overview
  • The set
  • Sizes
  • Rules
  • Code

Overview

Icons are inline SVG so they inherit text colour and size, in both themes and in forced-colors mode. There is no icon font and no sprite; every mock inlines the paths it needs. This is the whole set the mocks use.

The set

trashRemove holiday, delete
closeClose dialog, dismiss
chevron-downMenu and select affordance
plusAdd, request days
checkConfirm, confirmed glyph
teamMembers, team
alert-circleFailed or invalid
chevron-leftPrevious month
chevron-rightNext month
minusDecrease, indeterminate
selectSelect mode on the sheet
arrow-leftBack link
check-circleSuccess
refreshRetry, reconnect
alert-triangleWarning, over allowance
sign-outSign out
infoInformation
lockRead-only, locked setting
arrow-downDownload, sort descending
cloud-offOffline
mailInvitation
calendarCalendar, dates
userAccount

Sizes

icon--sm 16px (inside small controls and menus), default 20px, icon--lg 24px (period arrows, empty-state glyphs at 2rem+).

Rules

  • Style: outline, 2px stroke, round caps and joins, 24x24 viewBox, no fills (except the dots inside alert glyphs).
  • Decorative icons are aria-hidden="true" and sit next to a visible label. An icon-only control needs an aria-label on the button, never on the SVG.
  • An icon never carries state alone: the sheet's cell glyphs (✓ … ?) are text, and every status icon is paired with words.
  • Add an icon only when the mock needs it, in the same style, and add it to this page.

Code

<button class="btn btn--icon btn--ghost" type="button" aria-label="Next month">
  <svg class="icon icon--lg" aria-hidden="true" viewBox="0 0 24 24"><path d="m9 18 6-6-6-6"/></svg>
</button>
