Foundation · Typography

Typography

Two families, nine sizes, four weights and twelve role shorthands that components consume.

WCAG 2.2 AAStatus: stable

  • Size scale

Overview

Type is set by role, not by size. A component says font: var(--text-label) and inherits the family, size, weight and line height together; the scale beneath exists so roles can change in one place.

Families

--font-family-sansGreenlit — Time off, in colour. 0123456789
--font-family-displayGreenlit — Time off, in colour. 0123456789
--font-family-monoGreenlit — Time off, in colour. 0123456789

Inter carries the interface; Plus Jakarta Sans carries headings, the wordmark and the big allowance number. Both are named first with system fallbacks: the mocks and the product load no network fonts, and a missing font never changes layout enough to matter.

Measure

Long text stops at --layout-measure (65ch) so lines stay readable. Settings explanations and dialog bodies use it; the sheet and tables do not, because they are data, not prose.

Usage

  • Body is 16px; nothing is smaller than 12px (--font-size-xs), and 12px is for captions and badges only.
  • Numbers that line up use font-variant-numeric: tabular-nums: day counts, allowances, dates in lists, the sheet.
  • Sentence case everywhere. All-caps appears only in --text-overline labels, with --letter-spacing-wide.
  • Headings use the display family, tighter line height, and text-wrap: balance. Paragraphs use text-wrap: pretty.
  • --text-h1 is fluid (clamp) from 24px on a phone to 30px on a laptop; no other role changes size by breakpoint.
  • Users who raise their browser font size get proportional layouts: sizes are rem, never px.
