# Greenlit: L1 requirements

High-level requirements. Each L1 item is refined into L2 items with acceptance criteria in
`L2.md`; production code is written only against an L2 item.

## Problem

Managers of teams under ten people track vacation in a Google Sheet: one table per month, members
down the left, weekday initials and day numbers across the top, a colour in every cell. Red is a
weekend or holiday, blue is tentative, yellow is requested, green is confirmed. It works until two
people edit at once, someone forgets to ask, or the manager loses track of what is still yellow.

## Users

- **Manager**: owns the team, confirms requests, maintains holidays and membership.
- **Member**: colours their own days, sees the whole team's month.

## L1 requirements

| ID     | Requirement                                                                                                                                  |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| L1-001 | A manager creates a team, names its members and sets its time zone.                                                                          |
| L1-002 | Everyone on the team sees the same month: members down the side, weekday initials and day numbers across the top, weekends and holidays red. |
| L1-003 | A member marks their own days tentative (blue), then requests them (yellow), and clears them.                                                |
| L1-004 | The manager confirms requested days (green) or declines them back to tentative.                                                              |
| L1-005 | The manager maintains the team's holidays.                                                                                                   |
| L1-006 | A member signs in with an email and password; a manager invites members by email.                                                            |
| L1-007 | The app works on a phone with touch and on a desktop with the keyboard, and never uses colour as the only carrier of a day's state.          |
| L1-008 | The app is a responsive web application: a .NET API and an Angular frontend.                                                                 |
