# Detailed designs

One folder per subsystem, one per feature inside it: `docs/detailed-designs/<subsystem>/<feature>/README.md`
with its C4, class and sequence diagrams rendered beside it. Each design derives from L2
requirements in `docs/specs/L2.md` and precedes implementation (see `AGENTS.md`).

Subsystems planned:

- `identity-and-access/` — sign in, invitations, roles
- `teams/` — team, members, time zone, holidays
- `sheet/` — the month view and day status transitions
- `web-experience/` — shell, navigation, responsive behaviour
